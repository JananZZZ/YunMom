# First Round Brief — G1 YunMom Master

## Goal
Converge on the original YunMom identity without asking the user to design it.

## Inputs
- Product baseline
- User cloud-pillow reference (mood/material/comfort reference only)
- Art Direction and Character System

## Internal exploration
Create 6 internal YunMom directions. Keep the same world and only vary controlled dimensions:
- cloud silhouette / lobe rhythm
- face spacing and softness
- central nest depth
- plush softness / tactile read
- slight overall personality differences from serene to gently cheerful

Do not vary into different art styles.

## Internal curation
Hard-gate, then use `brand_guardian` + `visual_critic`. Reduce to 3 finalists.

## Finalist presentation
For each A/B/C, show:
- YunMom solo hero
- a small inset/secondary composition showing the Baby Nest with a clearly labeled non-production soft bundle proxy (not a medically verified fetus)
- one-line design distinction

Recommend one choice, but do not force it.

## After the user selects
If provisional: controlled edit of the chosen parent only.
If clearly approved and required reviews pass: promote the exact artifact to the `yunmom_master` aesthetic-Golden slot, then create:
- Character Lock Sheet
- front / 3/4 reference views
- expression sheet
- Cloud Puff sheet
- material/light swatch sheet
These become aesthetic identity references for later generation. They do not create medical, Token, implementation, or release approval.
