# Originality & Medical Visual Gates

## Originality gate
The user reference image defines softness, plush material, comfort, and the “baby nestled in a cloud pillow” emotional direction. It is not permission to clone a distinctive existing character design.

Codex must deliberately create original:
- cloud silhouette
- face proportion
- nest geometry
- Cloud Puff behavior
- star object language
- prop language
- screen composition

If a candidate feels too close to a reference rather than “inspired by the qualities,” reject and redesign.

## Baby medical visual gate
YunMom uses scientifically stage-informed growth art, but visual generation alone cannot self-certify medical correctness.

### Draft status
Codex may create exploratory Baby concepts using approved product requirements, but mark them `medical_status: unverified` until checked against approved medical source material.

### Aesthetic Golden and production evidence
A Baby anchor may become an aesthetic Golden only if:
1. gestational range is explicit;
2. each approved medical source has an ID, version, checksum, applicable range, and approval record;
3. proportions and stage-defining traits have a documented comparison;
4. conflicts are resolved conservatively;
5. an independent qualified medical reviewer, role/credential reference, review date, scope, verdict, and evidence hash are recorded.

Any locally archived clinical source and professional attestation also needs a sibling hash-bound provenance sidecar with explicit repository-safe privacy classification. Real patient content, unknown origin, or unclassified attachments are rejected rather than becoming visual evidence. Clinical-source rights/authorization must be recorded; a public-domain claim alone is insufficient without a `PUBLIC-CLINICAL-SOURCE:` evidence reference.

Missing any item leaves the asset `unverified` and blocks Golden promotion. Aesthetic approval does not create medical verification. Source hash/version or applicable-range changes make the verification and all dependent assets stale. Production/release use additionally requires the same-build platform and professional evidence defined by the engineering contract.

A Codex custom agent or model-based `medical` review is an adversarial advisory check only. It cannot supply a credential, create `VERIFIED`, or replace the qualified human reviewer and structured source-bound verification record.

### Never infer health from character
Baby visuals never represent individual fetal health, ultrasound findings, diagnosis, growth restriction, or prognosis. They are stage-based artistic representations only.
