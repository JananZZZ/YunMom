# Review Protocol

## Hard gates — pass/fail before scoring
1. Frozen product rules are respected.
2. YunMom identity is not humanized.
3. No guilt/task-pressure visual language.
4. Original IP is being developed; inspiration is not copied too closely.
5. Dynamic UI data is not baked into production background art.
6. Baby production asset has medical visual verification or is clearly marked unverified draft.
7. No safety/risk state is communicated through Baby distress.
8. The result is technically feasible at production quality.
9. Safety/Crisis meaning is not color-, motion-, sound-, haptic-, character-, or Widget-only.
10. P0 accessibility, maximum text, screen-reader order, focus, non-gesture alternative, contrast, and Reduce Motion are preserved.
11. Widget privacy, expiry, withdrawal, Gentle Closure, and deletion behavior match the frozen contract.
12. Provenance, parent lineage, semantic Token usage, and evidence tier are explicit.
13. Every persisted artifact is synthetic/de-identified or non-sensitive, and any sensitive external image path has both Provider-allowlist approval and per-send confirmation.
14. Font, icon, stock, third-party, user-reference, and generated-asset commercial/derivative rights are evidenced for the claimed use.

Any hard-gate failure = reject regardless of beauty.

## Heuristic aesthetic score (100, only after every hard gate passes)
- YunMom brand identity: 22
- Warmth / calm / low pressure: 18
- Premium craft / taste: 18
- Composition / hierarchy: 16
- Material / light / tactile quality: 12
- Consistency with valid Goldens: 8
- Production elegance/feasibility: 6

Suggested internal screening thresholds:
- S class: ≥93
- A class: ≥90
- B class: ≥86
Scores are screening aids, not objective truth. Safety, accessibility, privacy, medical validity, and release criteria are non-compensable gates and never receive a score that another category can offset. The user is the creative approver for aesthetic-Golden identity decisions only.

## Independent review
For S/A assets, main agent should delegate read-only review:
- `brand_guardian`: invariant/identity drift
- `visual_critic`: high-end aesthetic and emotional load
- `production_critic`: real implementation, responsive layout, performance
- `medical_visual_auditor`: Baby stage only, against approved source material

Add `accessibility_safety_critic` for P0, Safety, consent, deletion, Gentle Closure, and Widget surfaces. When named custom agents are unavailable, spawn independent read-only subagents using `REVIEWER_BRIEFS.md`. Do not disclose the preferred finalist or other reviews.

Do not let reviewers edit assets. Main agent synthesizes evidence.

## Integrated-screen rule
An isolated asset can pass and still fail in context. Final review occurs in the real screen screenshot/state.

In a user-authorized create/edit/implement or promotion workflow, the main agent records the result in the review registry. A pure review, critique, audit, or report returns the same structured result without writing any project file. A score cannot override a hard-gate failure.
