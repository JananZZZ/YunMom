# Character System

## YunMom immutable DNA
- White, large, pillow-like cloud creature
- Short-pile plush 3D material
- Minimal eyes, tiny nose, small mouth
- No human body, torso, legs, shoulders, or normal arms
- Manipulation occurs through temporary rounded `Cloud Puff` deformations
- Central/low Baby Nest is a defining feature
- Friendly and maternal in quality, but never pretending to be a human mother

## Face
Aim for long-term calm appeal. Avoid anime eyes, glass doll eyes, exaggerated smiles, teeth, pouty baby-mouth clichés, visible panic, or infantilizing expressions.

Allowed states: calm, soft smile, listening, thinking, sleepy, affectionate attention, mild delight.
Forbidden: crying, angry, frightened, disappointed, scolding, guilty, exhausted despair.

## Baby
- Baby is not the AI body.
- Same material universe as YunMom.
- Visual stage must follow versioned, approved gestational-stage sources and qualified independent review before aesthetic-Golden or production claims.
- Earlier stages must not be forced into newborn proportions merely for cuteness.
- Clothing/wrapping becomes more explicit only when stage-appropriate.
- No negative medical state encoded in the Baby.
- For a multi-BabySubject Episode, keep subject identity and asset provenance explicit. Do not imply that one shared pose, size, or expression represents the individual health of all fetuses.

## Anchor strategy
Start with a small set of approved gestational anchors, then interpolate visual stages between adjacent anchors. Do not independently reinvent each week.

The anchor weeks/ranges are defined by the MD-approved visual-source plan. Do not turn an illustrative or historical list into clinical authority. These remain art anchors, not individual-health or checkup claims.

## Props
Stars and size-comparison props belong to the same soft-material world. They should feel like designed collectible objects, not emoji, stock clip-art, or photoreal fruit.

## Cloud Puff
Cloud Puff is a local swelling from YunMom, continuous with the cloud body. No fingers, forearms, wrists, or tentacles. Use for touching Baby, holding stars, presenting fruit, guiding the camera interaction.
