# 云妈妈 YunMom · 动效与交互规范 V1.0.0

> **目标**：所有界面切换、状态改变、角色反馈都属于同一个“柔软空间”。动画要丰富，但绝不嘈杂；要丝滑，但不追求高速；要有情绪，但不制造动态不适。

---

# 1. 动效总原则

关键词：
> **连续、柔软、从容、轻盈、华丽但安静。**

硬性禁止：
- 突然硬切；
- 高速 Zoom；
- 高频弹跳；
- 连续震屏；
- 频闪；
- 高速旋转；
- 多个元素同时强动；
- 满屏粒子爆炸；
- 游戏式奖励动画；
- 医疗风险时全屏红色警报。

---

# 2. 时间尺度

建议基线：
- 微反馈：150–350ms
- 元素状态：350–700ms
- 空间切换：600–1000ms
- 情绪里程碑：1.2–2.5s
- Ambient 循环：8–30s

具体参数必须实机调，不用“越快越丝滑”的错误标准。

---

# 3. 全局运动语言

## 3.1 Continuity
页面不是“新页面覆盖旧页面”，而是同一空间改变。

优先使用：
- Shared Element
- Morph
- Scale
- Parallax
- Depth
- Opacity
- Cloud Occlusion
- Light Transition

少用：
- 硬 Push
- Bottom Sheet 盖屏
- 突然白屏

## 3.2 One Active Focus
同一时刻：
- 如果 Pregnancy Time 在切换，角色不做强动作；
- 如果星星完成，背景不同时做大变化；
- 如果风险卡展开，Ambient 降低存在感。

---

# 4. HOME → MEMORY

用户手指向右：
1. Living World 跟手移动；
2. YunMom + Baby 稍向右前移动，但不离开世界；
3. 左侧 Memory 内容从更深空间靠近；
4. 环境光连续；
5. 手势超过阈值完成切换；
6. 未超过阈值则柔和回弹。

不允许：
- 直接黑/白切；
- 强 3D 翻页。

---

# 5. HOME → CARE / Bento

用户向左：
1. HOME 世界向左；
2. YunMom + Baby 轻微后退缩小；
3. Bento 卡片从右侧深处出现；
4. 卡片由略虚到清晰；
5. 角色仍保留少量存在感；
6. 完成后 Bento 成为视觉焦点。

---

# 6. HOME → KNOW

向上：
- 感觉像视线抬向天空；
- YunMom 缩小成为顶部小陪伴；
- 知识卡从云层或上方出现；
- 不做“整页往上飞走”的高速效果。

---

# 7. Bento → Detail

点击卡片：
1. 卡片轻抬；
2. 周围卡片降低亮度/景深；
3. 选中卡片扩张；
4. 圆角、图标、背景位置连续 Morph；
5. 形成详情页。

返回：
- 左滑；
- 或 YunMom Home Button；
- 页面收缩回原卡位；
- Bento 恢复。

---

# 8. Pregnancy Time 动画

切换 `孕 19周+3天` ↔ `距离见面还有 144天`：

1. 云气轻聚；
2. 当前文字 Opacity 下降；
3. Blur 略增；
4. 云覆盖；
5. 新文字由同一区域聚合；
6. 云散。

建议 600–900ms。

Silent Day 禁止自动轮播。

---

# 9. YunMom 单击

单击：
- Scale 1 → 1.01~1.02；
- 轻微向用户靠近；
- 眼神转向用户；
- 小气泡从脸附近出现；
- Haptic 极轻（若开启）。

不弹 Bottom Sheet。

---

# 10. 长按语音

## 10.1 进入
满足长按阈值：
- 一次柔和 Haptic；
- YunMom 云体轻微“呼吸”；
- 进入 listening 表情；
- 云边出现轻声波。

## 10.2 录音中
- 声波跟随音量，但限制最大振幅；
- 不做传统跳动柱状条；
- 相机 Target 可在右上浮现。

## 10.3 松手
- 声波向 YunMom 收束；
- YunMom 进入 thinking；
- AI 可直接执行；
- 完成后 Receipt 轻浮起。

---

# 11. Camera Drag

长按后：
- 右上出现小 Camera Target；
- 不突兀，像一个淡淡目标泡。

拖动：
- 手指靠近目标，目标略放大；
- YunMom 眼神轻跟；
- 进入吸附区有一次 `magnetic_snap`；
- 松手进入相机。

中途取消：
- 用户把手移回；
- Target 淡出；
- 回到 Voice Mode；
- 不弹“操作已取消”。

---

# 12. AI Overlay

进入：
- 环境背景降清晰度；
- YunMom 保留；
- 云层略放大；
- 输入控件从云中自然出现。

退出：
- 输入控件融入云；
- 环境恢复；
- 不硬关 Modal。

---

# 13. Action Receipt

出现：
- 从相关操作区域轻浮起；
- 1–2 行；
- ✏️ / 🗑 固定可见；
- 不挡 YunMom 脸；
- 数秒后淡出。

编辑：
- Receipt 自身轻扩张成为小编辑态。

删除：
- 轻缩并淡出；
- 不做垃圾桶爆炸。

---

# 14. 星星

## 14.1 新任务
- 从 YunMom 云体边缘/内部轻浮出；
- 缓慢吸附；
- 轻旋转 2–5°；
- 不闪。

## 14.2 星群
星星相互轻微错位，形成小星座，不持续运动。

## 14.3 完成
1. 轻亮；
2. 少量星屑；
3. 星屑向 MEMORY 方向飘；
4. 整体 0.8–1.2s；
5. 结束恢复安静。

---

# 15. 风险 `!`

首次出现：
- Scale 0.92→1；
- 一次轻 Haptic；
- 可有一次极轻音；
- 之后静止。

若确有必要重复吸引注意：
- 间隔较久做一次很浅的呼吸；
- 不能每秒跳。

点击：
- Safety Card 从图标附近展开；
- 不全屏；
- 详情二次展开。

---

# 16. Silent Day 动效

- 星星不存在；
- Pregnancy Time 停止自动轮播；
- 停留后 Pregnancy Time 慢慢淡出；
- YunMom 与 Baby 的 idle 速度略降低；
- 粒子减少；
- 光更稳定；
- 不显示“今日全部完成”。

---

# 17. Baby Stage 过渡

阶段变化不能突然换模型。

推荐组合：
- Cloud Occlusion
- Crossfade
- Scale Interpolation
- Pose Continuity
- Local Morph

最好发生在自然时机：
- App 重新打开；
- 云层遮挡；
- 孕周节点；
- 大型里程碑动画。

---

# 18. 胎动记录反馈

用户记录“今天宝宝动得明显”后：
- 不立即机械响应；
- 随机延迟几秒；
- Baby 轻踢；
- 云枕小凹陷；
- 回弹；
- YunMom Cloud Puff 轻整理；
- 文案“今天也留下啦”短暂出现。

---

# 19. 水果道具

出现：
- Cloud Puff 先形成；
- 道具从云雾中出现；
- 小道具轻；
- 大西瓜对云体产生很小软体压陷；
- 结束自然收回云内。

不做魔术爆炸、彩带。

---

# 20. 天气过渡

天气状态通过插值切换：
- Sky Hue
- Light Temperature
- Cloud Opacity
- Particle Density
- Rim Light
- Far Cloud Speed

雨：
- 远景从极少到稳定；
- 不突然暴雨。

雪：
- 慢；
- 少；
- 远。

---

# 21. 时间过渡

日出→上午→正午→下午→日落→夜晚：
- 不整点切换；
- 在较长窗口内渐变；
- 用户应感觉“世界自然变了”，而不是“换皮肤”。

---

# 22. 声音系统

## 22.1 开关
- 交互声音：默认开，低音量
- 环境声音：默认关
- 遵从系统静音逻辑

## 22.2 音色
- soft puff
- airy whoosh
- warm wooden/glass chime
- very soft confirm tone

禁止：
- 宝宝哭；
- 真实医疗警报；
- 游戏金币；
- 高频叮咚；
- 默认胎心音。

---

# 23. Haptics

独立设置开关。

类型：
- `soft_tap`
- `soft_confirm`
- `magnetic_snap`
- `milestone`

使用：
- YunMom 单击：soft_tap
- 进入语音：soft_confirm
- Camera 吸附：magnetic_snap
- AI 写入：soft_confirm
- 重要里程碑：milestone

绝不连续强震。

---

# 24. 动态不适

当前 V1 不提供产品内“关闭所有动效”开关，但必须天然低刺激：
- 不高速旋转；
- 不强景深飞行；
- 不大范围摇晃；
- 不频闪；
- 不快速视差。

代码预留：
`motion_intensity`
未来可接系统 Reduce Motion，不改变当前设计方向。

---

# 25. 帧率与低端降级

目标：
- 支持 60fps 主交互。

低端允许：
- 减粒子；
- 减 Shader；
- 减背景模糊；
- 降环境层并发。

不得取消：
- Pregnancy Time；
- YunMom 基础状态；
- Baby 基础状态；
- 星星语义；
- Risk；
- 语音/相机手势反馈。

---

# 26. 动效验收

任何交互必须回答：
1. 是不是同一个空间的连续变化？
2. 是否出现两个以上强焦点？
3. 是否过快？
4. 是否可能让孕妈妈晕？
5. 是否真的增加理解或情绪价值？
6. 如果删除动画，功能是否仍清楚？
7. 动画是否有足够静止时间？
8. 风险状态是否没有被过度“演出”？
