# 云妈妈 YunMom · 形象设计与视觉角色圣经 V1.0.0

> **用途**：用于后续概念设计、3D/2.5D 制作、Rive 动画、插画、App 图标、Widget、道具、AI 辅助生成与美术验收。
>
> **核心参考**：用户提供的“白色短绒云枕抱着熟睡宝宝”的参考图。其核心不是具体造型复刻，而是：**柔软、安全、安静、高级短绒、枕头感、宝宝窝在其中的被承托感。**

---

# 1. 总体视觉命题

YunMom 不是传统“母婴卡通 App”，而是：

> **一个住在手机里的、仿佛可以触摸到的柔软孕期小世界。**

关键词：
- 温柔
- 柔软
- 清透
- 生动
- 安静
- 高级
- 轻盈
- 有生命感
- 可爱但不低幼
- 梦幻但不俗
- 丰富但不吵
- 长期耐看

最终视觉要达到：
> 第一眼可爱，长期耐看；  
> 第一眼柔软，长期不腻；  
> 动效很多，但心理感受安静。

---

# 2. 世界观

这个世界不是“现实医院的卡通版”，而是一个柔软的云上空间。

核心物理语言：
- 物体边缘软；
- 体积圆润；
- 光线柔；
- 材质大多有短绒、针织、软树脂、半透明柔光质感；
- 没有锋利角；
- 没有金属冷硬医疗器械感；
- 医疗图标也应“软化”处理，但不能失去识别性。

世界的中心永远是：
1. YunMom
2. Baby
3. Pregnancy Time

其它 UI 是这个世界里的“轻层”，不是盖在角色上的传统 App 控件。

---

# 3. YunMom 的角色定位

YunMom 是：
- AI 本体；
- 一个有生命的白色云枕；
- 承托宝宝的柔软存在；
- 操作入口；
- 陪伴者；
- 信息照料者。

YunMom 不是：
- 穿云朵衣服的人；
- 有人类身体的妈妈；
- 大头萌宠；
- 卡通医生；
- 天使；
- 神仙；
- 拟人化过强的“真人替代”。

---

# 4. YunMom 轮廓

## 4.1 基础形
整体像一个大型、宽厚、柔软的云枕。

建议特征：
- 横向略宽；
- 下部厚实，给人稳定承托感；
- 上部形成 3–5 个不完全对称的圆润云峰；
- 中央自然下凹，形成 Baby Nest；
- 不是标准天气图标式“几瓣云”；
- 轮廓应有“高级软体家具/收藏毛绒”的感觉。

## 4.2 比例目标
首页中：
- YunMom + Baby 应占视觉主体的大约一半以上；
- 不能缩成一个小 mascot；
- YunMom 必须像“一个空间”，Baby 才能舒适地窝进去。

## 4.3 轮廓禁区
禁止：
- 细腰；
- 肩膀；
- 人腿；
- 人躯干；
- 明显胳膊；
- 手掌；
- 翅膀；
- 皇冠；
- 围裙；
- 护士帽；
- 妈妈发型；
- 任何把“云妈妈”变成人形妈妈的元素。

---

# 5. YunMom 的脸

设计目标：
> **看 100 次也不烦。**

## 5.1 眼睛
- 小；
- 简洁；
- 低对比；
- 像软绒刺绣或极细绒线；
- 可闭眼、半睁、轻看 Baby、轻看用户；
- 不使用玻璃珠大眼；
- 不使用高光闪闪动漫眼；
- 不做眼泪大颗粒。

## 5.2 鼻子
- 极小；
- 弱化；
- 可以是极浅绒线点或小小体积凸起；
- 只用于脸部完整性。

## 5.3 嘴
- 很小；
- 温和弧线；
- 可轻微变化；
- 不大张嘴；
- 不露牙；
- 不夸张撅嘴；
- 不做婴儿式“3”嘴常驻。

## 5.4 眉
非必需。
若使用：
- 极淡；
- 只帮助表达思考、轻微关注；
- 不用于生气、担忧。

## 5.5 脸部位置
脸应位于 YunMom 上部中心偏前，不能太高，以免像“头”与“身体”。
Baby 应自然位于脸的下方/怀中区域，形成“照看”关系。

---

# 6. YunMom 表情范围

允许：
- 平静微笑；
- 轻松；
- 安心；
- 认真；
- 思考；
- 轻微惊喜；
- 睡意；
- 倾听；
- 温柔看 Baby；
- 温柔看用户。

禁止：
- 恐惧；
- 崩溃；
- 生气；
- 责备；
- 哭；
- 失望；
- 嫌弃；
- 焦虑抖动；
- 因用户漏任务而明显负面。

Professional Tone：
- 动作更少；
- 目光稳定；
- 表情仍然温柔；
- 不需要戴眼镜、拿病历变“医生角色”。

Safety：
- 角色保持正常平静；
- 风险由 UI 右下角 `!` 承担；
- YunMom 不演恐慌。

# 7. YunMom 的“手”：Cloud Puff

YunMom 没有传统手。

当需要：
- 托星星；
- 拿桃子；
- 抱西瓜；
- 轻碰 Baby；
- 指向相机；
- 接住某个 UI 物体；

使用 **Cloud Puff**。

## 7.1 Cloud Puff 形态
- 云体某个局部慢慢鼓出；
- 像一个圆润小云团；
- 与主体之间无“手臂关节”；
- 不出现五指；
- 不像章鱼触手；
- 结束后自然融回主体。

## 7.2 Cloud Puff 动作语言
动作慢、软、短：
- 托；
- 推；
- 轻碰；
- 抱住；
- 收回。

不做：
- 指责式指人；
- 快速拍打；
- 用力抓。

---

# 8. 核心材质：Short-Pile Plush 3D

YunMom 的核心视觉定义：
> **短绒 3D 毛绒玩具质感。**

不是：
- 光滑塑料；
- 果冻；
- 云烟；
- 棉花糖；
- 写实动物毛；
- 长毛绒玩具。

## 8.1 表面
- 绒毛很短；
- 密度均匀；
- 非常干净；
- 有轻微方向性；
- 边缘可产生柔软毛边；
- 不能显脏、结块或真实毛发杂乱。

## 8.2 渲染建议
视觉层面可用：
- soft base color
- microfiber normal
- subtle directional fur highlight
- soft rim light
- low-frequency noise
- soft contact shadow
- very subtle subsurface-like softness

不做实时逐根毛模拟。

---

# 9. Baby 的视觉定位

Baby：
- 不是 AI；
- 是孕周成长的视觉主角；
- 与 YunMom 使用完全统一的材质世界；
- 形态随孕周科学演进；
- 是“成长视觉演绎”，不是超声模拟、医学影像或发育诊断。

## 9.1 皮肤
不要写实皮肤：
- 奶油色；
- 柔软；
- 极细短绒；
- 无真实毛孔；
- 无湿润反光；
- 无蜡像感；
- 无真实胎儿皮肤的医学写实。

## 9.2 情绪
Baby 常见状态：
- 睡；
- 蜷；
- 舒展；
- 轻动；
- 碰 YunMom；
- 安静醒一下；
- 与道具轻互动。

绝不：
- 因妈妈数据哭；
- 表现病态；
- 表现疼痛；
- “不开心”。

---

# 10. Baby 的科学形态原则

用户要求根据不同孕周科学形态生成，因此不能从怀孕早期就画成一个新生儿。

核心规则：
1. 每个阶段先有医学结构参考；
2. 再进行 Plush 化；
3. 美术不能把阶段特征全部“萌化掉”；
4. 不能为了穿小衣服而把早期胎儿画成人形 newborn；
5. 所有阶段最终由产科/医学内容审核后锁定。

---

4. 11–12 周
5. 13–14 周

14. 36–37 周
15. 38–40 周

> 这是美术资产分组，不是医学产检节点。

每套都必须定义：
- 头身比例；
- 四肢比例；
- 躯干比例；

- 可用动作；
- 禁止动作；
- 与上一阶段的过渡方式；
- 与下一阶段的预留变形。

# 12. Baby 衣服

用户希望 Baby 穿着软萌毛绒/针织小衣服。

但规则必须是：
- 早期更适合抽象软包裹、绒毯、柔软“茧”式包覆；
- 形态成熟后逐渐引入更明显的小衣服；
- 服装不能让胎儿看起来提前变成新生儿；
- 不固定“粉女蓝男”。

## 材质
- 针织；
- 细绒；
- 包被；
- 软布；
- 极简无品牌图案。

## 色彩
- 奶白；
- 淡粉；
- 淡蓝；
- 淡杏；
- 薰衣草；
- 浅珊瑚。

# 15. 水果与大小类比

这是重要品牌互动。

## 15.1 道具
可用经内容审核的：
- 桃子；
- 柠檬；
- 牛油果；
- 甜瓜；
- 西瓜；
- 其它日常物体。

## 15.2 材质
道具也属于同一软质世界：
- 软玩具；
- 半短绒；
- 低反光；
- 不写实摄影水果。

## 15.3 动作
YunMom 从云体“变出” Cloud Puff 托住道具。
小水果轻松托住。
大西瓜可让 Cloud Puff 和云体轻微压陷，增加趣味。

## 15.4 语义
只做趣味类比，不表示用户宝宝真实测量大小。

# 16. 星星角色资产

星星不是普通扁平 icon，而是产品的核心物件。

## 16.1 造型
- 五角或经过原创化的柔软星形；
- 所有尖角圆润；
- 有 3D 体积；
- 可略微鼓起；
- 不锐利。

## 16.2 材质
比 YunMom 略光滑，但仍然柔和。
可像：
- 半透明软树脂；
- 柔光搪胶；
- 软质玩具。

不做金属镜面。

## 16.3 颜色
- 浅天蓝；
- 浅珊瑚粉；
- 浅紫；
- 柔金。

## 16.4 星群
多个任务聚合时：
- 大小轻微不同；
- 有前后景；
- 只有一颗主亮；
- 不能像“徽章未读 9+”。

主题固定：
> **一朵云抱着一颗小星星。**

## 17.1 构图
- 云为主；
- 星星位于云的怀抱/凹陷区域；
- 极简；

## 17.2 禁止
- Baby；
- 爱心堆叠；
- 红十字；
- 孕周数字；
- 文字；
- 太多小元素。

## 17.3 材质
可以体现短绒/软质，但在小尺寸下必须保持图形清楚。

# 19. Risk `!`

不是角色，不做毛绒情绪化。
设计：
- 右下角；
- 暖珊瑚红；
- 圆形软质；
- 中间清晰 `!`；
- 边缘柔和；
- 不用警示三角；
- 不闪烁。

必须“明显能看到”，但不能像系统故障。

# 21. 光照

## 日出
- 偏暖；
- 奶油粉光；
- 云边浅金。

## 白天
- 明亮；
- 清透；
- 空气蓝；
- 阴影柔软。

## 下午
- 略暖；
- 光源更低；
- 角色体积感稍强。

## 日落
- 淡粉 + 蓝 + 轻紫；
- 是重要“漂亮时段”；
- 不能橙红过饱和。

## 夜晚
- 深蓝紫但不黑；
- 月光柔；
- Baby 与 YunMom 仍清楚；
- 不孤独、不阴森。

---

# 22. 天气

## 晴
- 少量柔光粒子；
- 远景轻云。

## 阴
- 柔和漫反射；
- 色彩仍有生命，不灰蒙。

## 雨
- 雨主要在远景；
- 不打湿 YunMom；
- 不雷；
- 不闪电；
- 节奏更安静。

## 雪
- 缓慢；
- 远景；
- 不做圣诞皮肤。

---

# 23. Silent Day 的角色视觉

- Baby 更安静；
- YunMom 更慢；
- 星星不存在；
- 背景粒子减少；
- Pregnancy Time 停止轮播；
- 角色可以睡、轻呼吸、轻看彼此；
- 不能通过“打勾”告诉用户完成任务。

---

# 24. Professional / Safety 视觉

## Professional
- 角色动画降低；
- 不换衣服；
- 不拿听诊器；
- 不戴眼镜；
- 只是更安静、更稳定。

## Safety
- YunMom、Baby 不进入负面状态；
- 右下角 `!` 承担风险；
- 安全卡负责文字。

---

# 25. Gentle Closure 视觉

若进入 Quiet Archive：
- 停止成长庆祝；
- 停止水果；
- 停止预产期倒数；
- 空间更克制；
- YunMom 可保留；
- Baby 是否显示由用户决定；
- 不默认翅膀、天使、星星升天、纪念碑等象征；
- 不做悲情背景音乐。

---

# 26. AI 辅助美术生成

AI 可用于：
- 概念草图；
- 情绪板；
- 姿势；
- 材质探索；
- 道具；
- 分镜。

不能直接把不同 Prompt 的随机输出当最终运行资产。

## 26.1 YunMom Prompt 核心
> soft white cloud pillow creature, premium short-pile plush toy texture, minimal embroidered face, no human body, no traditional arms, soft cloud puffs, gentle maternal calm, elegant premium collectible toy, airy pastel environment, soft studio lighting, non-childish, minimal and warm

## 26.2 Baby Prompt 核心
> medically stage-referenced fetal/baby proportions translated into the same premium short-pile plush 3D toy language, curled comfortably in a soft cloud pillow nest, non-realistic soft plush skin, knitted wrapping/clothing only when stage-appropriate, serene, gentle, premium collectible, pastel pink blue white palette

## 26.3 禁止倾向
- hyper-realistic fetus
- wet skin
- medical specimen
- anime big eyes
- plastic vinyl
- exaggerated chibi
- crying
- distressed
- sick
- horror
- angel wings for loss flow

每一版必须回答：

2. 是否像一个真的可以靠上去的软云枕？
3. 脸是否足够克制和耐看？
4. 是否避免大眼萌宠低幼感？

6. Baby 是否没有明显违背阶段形态？
7. 早期 Baby 是否没有错误 newborn 化？
8. 服装是否没有掩盖阶段比例？
9. 角色是否不会给妈妈负罪感？

12. Widget 缩小后还能辨认吗？
13. App Icon 是否足够独特？
14. 水果道具是否统一世界观？
