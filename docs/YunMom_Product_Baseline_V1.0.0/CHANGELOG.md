# CHANGELOG

## V1.0.0 — 2026-08-10

首次冻结当前 YunMom 产品基线。

本版本：
- 完整汇总此前多轮讨论中已经最终确定的产品方向；
- 保留所有未被明确修改的既有设计；
- 将 Bento 进一步收束为低负担 6 领域结构；
- 将医疗风险 UI 固定为首页右下角温和 `!`；
- 锁定 YunMom 为短绒 3D 白色云枕角色；
- 锁定 Baby 为同世界观的孕周科学阶段毛绒角色；
- 增补声音与 Haptic 可关闭；
- 增补 No Health Data Backend + Minimal AI Gateway + BYOK；
- 增补 Gentle Closure；
- 增补异常、无网、权限、备份、日志、测试、数据迁移和技术红线；
- 增补页面/状态矩阵和高保真验收基线。
