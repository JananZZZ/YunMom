# Architecture Decision Records

ADRs select an implementation that already fits the frozen YunMom contracts. They cannot alter
product scope, medical meaning, privacy, security, deletion, platform parity or release gates.

Use the next sequential `ADR-NNNN-short-title.md` and include:

- status: `proposed`, `accepted`, `superseded` or `rejected`;
- work-item ID and contract IDs;
- context and non-negotiable constraints;
- evaluated options and objective evidence;
- decision and consequences;
- rollback/compatibility impact;
- TECH/QA plus required domain reviewers.

Anything outside the frozen contract follows `CHG-001`, not this directory.
