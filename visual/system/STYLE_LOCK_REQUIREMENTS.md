# Style Lock Sheet checklist

After YunMom Master is approved, create one review sheet containing:
- approved YunMom master hero
- front/3-4 view
- face close-up
- plush material crop
- Cloud Puff example
- Baby Nest example using a clearly non-medical proxy unless a scoped Baby asset is already medically verified
- star prop
- color/light swatches
- YES examples and small NO examples

This sheet becomes an aesthetic reference for later generation. It is not a Token Bundle, medical verification, implementation acceptance, or release signature; contract or parent invalidation can make it stale.
